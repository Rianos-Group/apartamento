# Simulador del apartamento

Simulador de leasing habitacional (Banco Davivienda) para comparar escenarios de pago. Todo el cálculo corre en el navegador, no hay backend.

## Abrir localmente

Haz doble clic en `index.html` (o ábrelo con tu navegador). No necesita servidor ni instalación.

## Publicar en GitHub Pages

1. Sube `index.html` a la raíz del repositorio (`git add index.html && git commit -m "simulador" && git push`).
2. En GitHub: **Settings → Pages → Deploy from branch → `main` / `root`**.

La página quedará disponible en `https://<usuario>.github.io/<repo>/`.
